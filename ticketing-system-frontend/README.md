# Ticketing System Frontend

Next.js frontend for the Ticketing System application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- User authentication (login/register)
- User dashboard to create and view tickets
- Support agent view to manage all tickets
- Admin panel for user and ticket management
- Ticket detail pages with comments
- Search and filter functionality
